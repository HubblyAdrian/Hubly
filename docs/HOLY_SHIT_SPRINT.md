# The "Holy Shit" Sprint

**Goal:** Every new customer gets 5–10 moments where they literally say *“Holy shit…”*

**Bar (silent video test):**

> If someone recorded a first-time user with **no audio**, could they tell Hubly is powered by AI just by watching the screen?

If not — the experience still isn’t visual enough.

---

## Create moments

| # | Moment | What they see |
|---|--------|----------------|
| 1 | “I’ll build your business” (0–10s) | Website starts building immediately |
| 2 | “I found something…” | Homepage rewrite — visible |
| 3 | Surfaces land | Booking + logo + packages (no reports) |
| 4 | Assumption, not a question | Built first; optional expand later |
| 5 | Reveal | 🎉 Your business is ready — clickable Website / Booking / CRM / Packages |

## Alive Home

Not software tiles first.

1. **Good afternoon Adrian.**  
2. **While you were away…** (✓ improvements)  
3. **Big website preview**  
4. **Today’s Recommendation** (Apply / Dismiss)  
5. **AI Activity Feed** (business commits, not logs)  
6. Revenue · Customers · Jobs  

Morning variant: *Since yesterday I…* improved SEO, keywords, pricing, landing page, etc.

---

## Gate

```bash
npm run check:holy-shit
```
